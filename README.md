# SworkS

在自己电脑上运行的家教工作台：收集、整理好题，并记录学生的作答情况。

截图、图片链接、Markdown 或一段文字，粘贴进来就能保存；再给它写笔记、答案和解析，标上题型、难度和考点，记录每个学生做得怎么样，之后随时找回来。所有数据都存放在你自己电脑上的一个文件夹里，不需要注册账号，也不依赖任何云服务。

## 它能做什么

- **收一道题很快**：打开“收一道题”，按 `Ctrl+V` 粘贴截图就能保存。标题、学科、学段都可以先空着。
- **一道题可以有多张图和多段文字**：图片、Markdown、普通文字自由组合，随时调整顺序。
- **笔记、答案、解析分开记**：每道题可以有多条，都用 Markdown 书写，支持 `$x^2$` 这样的公式，以及类似 Obsidian 的提示框（callout）。
- **资料也能单独保存**：专题摘录、一组还没整理的截图，可以作为“资料”保存；以后再从中挑出内容建成题目。暂时来不及整理的，先放进“收件箱”。
- **找得回来**：搜索会同时查找标题、题干、图片说明、笔记、答案、解析、标签、属性和来源备注，并告诉你是在哪里命中的；左侧导航树可以按标签、考点、难度、题型、学科、学段筛选，还能按难度排序。
- **题型、难度、考点，以及你自己的属性**：预置题型、难度（容易→困难）和考点树（可以粘贴一份大纲导入）；也可以自己加“年份”“地区”“教材章节”这类属性。标签可以用 `/` 分层，例如 `方法/换元`。
- **记录学生的作答**：每个学生每做一次题记一条（对 / 半对 / 错 / 不会、觉得难不难、备注）。自动统计做过几次、错了几次、当前错题和薄弱考点，一键导出某个学生的错题。
- **整理起来快**：多选后可以批量加标签、设学科学段、设属性、记录作答、导出或移到回收站；支持键盘操作和 `Ctrl+K` 查找与跳转。
- **数据可以带走**：一键生成完整备份，并能在新的位置恢复；也可以把选中的题目导出为普通的 Markdown 文件，在别的软件里阅读。

## 安装

需要先安装：

- [Node.js](https://nodejs.org/) 24 或更新版本
- [pnpm](https://pnpm.io/)（例如运行 `npm install -g pnpm`）

然后下载本项目，在项目文件夹中运行：

```bash
pnpm install --frozen-lockfile
pnpm build
```

安装时会准备 SQLite 数据库组件。大多数系统会直接下载现成的版本；如果你的系统没有现成版本，需要先装好 C/C++ 编译工具。

## 启动与使用

```bash
pnpm start -- --data-dir ./sworks-data
```

终端会显示访问地址和数据文件夹的位置，例如：

```text
SworkS 0.1.0 已启动
  访问地址：http://127.0.0.1:4821
  数据目录：/Users/you/sworks-data
```

用浏览器打开访问地址即可开始使用。用完在终端按 `Ctrl+C` 停止。

启动参数：

| 参数 | 说明 |
| --- | --- |
| `--data-dir <文件夹>` | 数据存放位置。不指定时，依次使用环境变量 `SWORKS_DATA_DIR`、程序所在文件夹下的 `sworks-data`，不会因为你在哪个目录启动而变化 |
| `--port <端口>` | 端口号，默认 4821 |
| `--allow-fake-ip-dns` | 见下文“图片链接无法保存” |

SworkS 只允许本机访问，不支持局域网或远程访问。

### 收一道题

1. 点左侧的 **收一道题**。
2. 点一下页面下方的虚线收录区，按 `Ctrl+V`（macOS 上是 `⌘V`）粘贴截图或文字；也可以把图片拖进去，或者用按钮添加：
   - **Markdown**：可以写公式、列表、表格等
   - **普通文字**：按原样显示，里面的 `#`、`**` 等符号不会被当成格式；需要时可以点“转为 Markdown”
   - **图片**：从电脑中选择图片（支持 PNG、JPEG、WebP、GIF，以及 iPhone 的 HEIC/HEIF 与 AVIF）。新收录的截图会转成无损 WebP、照片转成 WebP 以节省空间，不改颜色，去掉拍摄位置等元数据；可以在“设置”里调整或关闭
   - **图片 URL**：填网上图片的地址，SworkS 会把图片下载下来保存
   - **导入 .md / .txt**：导入单个文本文件
3. 用每一块右上角的箭头调整顺序。
4. 点 **保存**（或按 `Ctrl+S`）。看到“已保存”才表示数据真正写入了磁盘。

在编辑框里粘贴时，内容会写进正在编辑的这一块，不会新建内容块。在 Markdown 编辑框里粘贴截图，会自动插入这张图片。

### 笔记、答案与解析

在题目下方点 **+ 笔记**、**+ 答案** 或 **+ 解析**。每条都可以有标题（例如“我的解法”“参考解析”），正文用 Markdown 书写。宽屏时可以一边写源码一边看预览。

公式与提示框示例：

```markdown
行内公式 $a+b\ge 2\sqrt{ab}$，独立一行的公式：

$$\int_0^1 x\,dx = \frac{1}{2}$$

> [!tip] 换元提醒
> 先令 $t=x^2$，再检查取值范围。

> [!answer]- 展开参考答案
> 标题后面加 `-` 表示默认折叠，加 `+` 表示默认展开。

> [!note] 解题过程
> 第一种思路。
>
> > [!warning] 易漏条件
> > 提示框可以嵌套。
```

常用的提示框类型有 `note`、`tip`、`warning`、`question`、`example`、`answer`、`solution` 等，大小写都可以；不认识的类型也会以通用样式显示。

### 资料与收件箱

- **收一份资料**：适合专题摘录、一组截图、文字材料。资料可以一直作为资料保存，也能被搜索。
- **收件箱**：显示状态为“待整理”的资料。整理完后，把资料状态改为“已整理”即可，资料本身不会消失。
- **从资料建题**：打开资料，点 **从资料建题**，勾选要用的内容块，点 **用所选内容建题**。新题目会记住它来自哪份资料，之后题目和资料各自修改，互不影响。

### 搜索、筛选与导航

- 用空格分隔多个关键词时，表示“同时包含”；英文不区分大小写。
- 左侧导航列出标签树、考点、难度、题型、学科、学段，括号里是数量。点一下只看这一类，再点一下取消；按住 `Ctrl`（macOS 上是 `⌘`）点击可以叠加条件。点父级（例如考点“函数”）会包含它下面的全部子级。
- 多选标签时，显示的是“包含全部所选标签”的题目；同一个属性选多个值时，显示“任一”。
- 可以按“最近添加”“最近修改”排序，也可以按难度、题型排序；修改笔记也算修改了这道题。
- 在列表里按空格可以快速预览题目（含答案、解析），不用打开编辑页。
- 按 `Ctrl+K` 可以按关键词跳到题目、资料、标签、考点、学生或页面。
- 搜索不会识别图片里的文字。

### 多选与批量操作

- 勾选一项，再按住 `Shift` 勾选另一项，可以选中中间的全部；`Ctrl+A` 全选已加载的项；当条件下超过一页时，可以点“选择全部 N 项”。
- 选中后，顶部会出现批量操作栏：加标签、移除标签、设学科、设学段、设属性（例如统一设难度、追加考点）、记录作答、导出为 Markdown、移到回收站。资料还可以批量改“待整理 / 已整理”。
- 加标签、移除标签、移到回收站之后，提示里有“撤销”。
- 也可以把选中的题目直接拖到左侧的标签或考点上。
- 键盘：`J`/`K`（或方向键）移动，`X` 选中，`Enter` 打开，`空格` 预览，`/` 搜索，`Esc` 取消选择。

### 属性与考点

- 题目页的属性面板里可以设置学科、学段、题型、难度、考点、标签、来源备注，以及你自己添加的属性。难度、题型这类选项不多的，点一下即可；考点可以搜索，也可以直接输入“函数/单调性”新建。
- **数据管理 → 属性与考点**：新建属性（文本、数字、日期、勾选、单选、多选），调整顺序、改名、改类型、选择是否在左侧栏列出，或归档。改类型时已有的取值会跟着转换（例如文本改为单选时，不同的文字各变成一个选项），转换前会先告诉你会改动多少题目，改完也可以撤销。单选、多选的选项可以有下级：第一次新建下级时会说明这样做的影响。左侧栏里属性的标题上点右键，也可以选择不再列出它。
- 考点树可以一个个新建，也可以点 **导入大纲**，粘贴一份用缩进、`-` 列表或 `#` 标题表示层级的大纲。选项可以拖动调整顺序和上下级，选中后按 `F2` 或双击改名，也能合并、删除。
- 选项改名、移动不会改变题目的修改时间；删除或合并选项会同步修改用到它的题目。

### 学生与作答记录

- 在 **学生** 页添加学生。在题目页的“作答记录”里选学生、选结果（对 / 半对 / 错 / 不会）、主观难度和备注，点 **记录**；看到“已记录”才表示保存成功。作答记录单独保存，不影响题目本身。
- 在题目列表里点 **按学生查看**，每道题会显示这个学生做过几次、错了几次、最近一次的结果；还可以只看“未做过”“做错过”“最近一次没做对”的题。多选后可以一次给多道题记录作答。
- 学生页显示做过的题、正确率、当前错题、薄弱考点（按考点树逐级汇总没做对的比例，作答少于 3 次的不算），以及全部作答记录；可以把当前错题导出为 Markdown。

### 数据管理

打开左侧的 **数据管理**：

- **学科、学段**：调整候选顺序、改名、合并到另一个值、从所有题目上清除，或移出候选。
- **标签**：按层级列出。改名时填写完整路径即可移到别的上级下；与已有标签同名时会自动合并。删除标签会从所有题目和资料上移除它（题目本身不受影响）。
- 这些操作会同步修改用到它们的题目。如果这些题目正开在其他页面里，那边会提示“已在别处修改”，不会把旧的值写回去。
- 删除、合并、清除之后，提示里有“撤销”。如果这期间相关的题目或标签又被改过，撤销会被拒绝，不会覆盖之后的修改。

### 删除与恢复

删除的题目、资料、笔记都会进入 **回收站**，随时可以恢复。删除一道题不会影响它的来源资料，也不会删掉其他题目共用的图片。

### 同时在两个页面编辑

如果同一道题在另一个页面被修改过，这里保存时会提示冲突，不会覆盖对方的修改。你可以重新加载最新版本、把当前内容另存为一道新题，或者先复制当前内容。

同一个浏览器里开着的其他页面会自动同步：没有未保存修改的页面会直接显示最新内容；有未保存修改的页面会立即提示“已在别处修改”。

## 备份、恢复与导出

### 完整备份

打开 **备份与导出**，点 **生成完整备份**。备份包含所有题目、资料、笔记、标签、属性与考点、学生与作答记录和原始图片，保存在数据文件夹的 `backups/` 里，页面上也可以直接下载。

建议定期备份，并**把备份文件另存到其他磁盘或位置**。备份里有你的全部笔记、来源链接和学生的作答记录，请不要当作公开分享的文件。旧版本 SworkS 生成的备份也可以恢复。

### 从备份恢复

恢复需要在终端中进行，并且只能恢复到一个**新的空文件夹**：

```bash
# 1. 先按 Ctrl+C 停止 SworkS
# 2. 恢复到新文件夹
pnpm restore -- --input ./SworkS-backup-20260925-120000Z.sworks.zip --data-dir ./sworks-restored
# 3. 用恢复出来的文件夹启动
pnpm start -- --data-dir ./sworks-restored
```

恢复会先完整检查备份文件，全部检查通过后才会写入目标文件夹。如果备份文件已损坏、被改动过，或者来自更新版本的 SworkS，恢复会停止，不会改动任何已有数据。

### 导出为 Markdown

在题目列表中勾选题目，点 **导出所选为 Markdown**；或者在题目页点 **导出**。你会得到一个压缩包：每道题一个 `.md` 文件，图片放在 `assets/` 文件夹里。文件开头的元信息里有标签和属性（考点写成 `函数/单调性` 这样的路径），在 Obsidian 里可以直接看到。公式和提示框按原样保留，不同的 Markdown 阅读器显示效果可能不同。导出的文件不包含学生与作答记录。

导出是为了在别的地方阅读，不能代替完整备份。

## 数据存放在哪里

```text
sworks-data/
  db.sqlite3      数据库
  assets/         原始图片与导入的文件
  backups/        完整备份，以及升级前的自动安全备份
  tmp/            临时文件
```

- 同一个数据文件夹同时只能被一个 SworkS 使用。
- 升级 SworkS 后，如果数据库需要升级，会先自动在 `backups/` 里做一份安全备份。
- 如果数据库文件损坏，SworkS 会报错并保持原样，不会自动重建。请从备份恢复到新文件夹。

## 常见问题

**端口被占用怎么办？**
换一个端口启动，例如 `pnpm start -- --data-dir ./sworks-data --port 4900`。

**提示“数据目录非空但没有 db.sqlite3”？**
你指定的文件夹里已经有别的文件。为了不覆盖它们，SworkS 拒绝在这里新建数据库。请换一个空文件夹，或指向正确的数据文件夹。

**图片链接无法保存？**
为了安全，SworkS 只从公网地址下载图片，不会访问本机或局域网里的地址。下载失败时，题目照样会保存，图片位置会显示原链接和失败原因，你可以点“重试下载”，或者“手动补传”一张本地图片。

如果错误提示中出现 `198.18.x.x`，通常说明你所在网络的 DNS（或你使用的代理软件）开启了 fake-ip 模式，把外部网站都解析到了这个保留地址段。确认如此时，可以加上 `--allow-fake-ip-dns` 启动，额外允许这一段地址。请注意：如果这个 DNS 把局域网里的设备名也解析到这一段，开启后图片下载有可能间接访问到局域网设备。

**图片会不会从网上加载？**
不会。保存后的图片都从本机读取；还没下载成功的图片只显示占位和原链接。

**可以多人使用或放在服务器上吗？**
目前不支持。SworkS 是单人使用、只在本机访问的工具，没有登录功能。

## 目前不包含的功能

- 识别图片中的文字（OCR），以及 AI 解题、自动打标签
- PDF 阅读、框选切题、自动拆题，以及批量导入整个文件夹
- 所见即所得编辑、Obsidian 双链（`[[…]]`）与插件
- 云同步、多人协作、历史版本
- 讲义/试卷编辑与 PDF 导出
- 按遗忘曲线的复习提醒（作答记录已经按次保存，以后可以接入）
- 自动保存（有保存按钮、`Ctrl+S`，以及未保存提示）
- 回收站永久清空；删除的内容和图片目前会一直保留
- 针对手机的界面优化

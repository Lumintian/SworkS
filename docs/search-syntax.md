# 检索语法

题目、资料列表上方的搜索框支持一套简单的查询语言。所有筛选条件都写在这一个框里：点左侧导航、用“条件”面板、点小标签上的 ×，改的都是这段文字。地址栏里只有它（`q=`），所以复制链接、加书签、保存为“常用检索”都能原样还原。

全角与半角符号等价：`：（）“”－！｜` 与 `:()"" - ! |` 相同，全角字母数字也能命中半角内容。英文不区分大小写。

## 基本写法

| 写法 | 含义 |
| --- | --- |
| `函数 最值` | 同时包含两个词（空格 = “且”） |
| `函数 OR 数列`、`函数 \| 数列` | 包含其一（`OR` 必须大写） |
| `-向量`、`!向量` | 不包含 |
| `"二次 函数"`、`“二次 函数”` | 短语（可以跨换行）；引号里的 `\"`、`\\` 是转义 |
| `(函数 OR 数列) 最值` | 括号分组 |

优先级：取反 > OR > 空格。所以 `a b OR c` 是“a，并且（b 或 c）”。

`f(x)`、`sin(2x)`、`10:30`、网址这类写法按原样查找，不会被当成括号或字段。

## 字段条件

写成 `键:值`（冒号可以是全角）。同一个条件里用逗号分隔多个值表示“或”：`学科:数学,物理`。值里有空格或逗号时加引号：`标签:"高考 真题"`。

| 键 | 取值 |
| --- | --- |
| `标题:` `正文:`（`题干:`）`笔记:` `答案:` `解析:` `来源:` | 只在这个字段里找这个词 |
| `标签:`，或直接写 `#路径` | 标签，含下级：`#数学` 也匹配 `数学/函数`；`标签:无` = 没有标签 |
| `学科:` `学段:` | 精确的值；`无` = 未设置 |
| `状态:` | 资料的整理状态：`待整理` / `已整理` |
| `创建:` `修改:` | 日期，见下文 |
| `有:` | `答案` `解析` `笔记` `图片` `标签` `来源` `标题`，或某个属性名（= 这个属性已设置） |
| `学生:` | `名字`（做过）、`名字/没做`、`名字/错过`、`名字/最近错`；同名学生写 `名字#ID前4位` |
| `范围:` | 让没写字段的词只在这些地方找：`标题 正文 笔记 答案 解析 来源 标签 属性`，例如 `二次函数 范围:标题,标签` |

键不区分大小写，也可以用英文：`title` `content` `note` `answer` `solution` `source` `tag` `subject` `stage` `status` `created` `updated` `has` `student` `in`。

## 属性

自定义属性直接用属性名做键：

- **单选、多选**：写选项的路径，含下级。`题型:英语/完型填空`；只写末级也可以：`题型:完型填空`。末级名在不同上级下重名时（`通用/选择`、`英语/选择`）两者都会匹配，并提示你写完整路径。`无` = 未设置，`*` 或 `任意` = 已设置。
- **有顺序的单选**（例如难度）可以比较：`难度:>=较难`、`难度:<中档`、`难度:较易..较难`。
- **数字**：`年份:2024`、`年份:>=2020`、`年份:2020..2024`。
- **日期**：同“创建”。
- **勾选**：`重点:是` / `重点:否`。
- **文本**：包含这段文字，`出处:人教版`；`无`、`*`。

属性名里有空格时给键加引号：`"教材 章节":第一章`。属性名与上面的键重名（例如叫“标题”）时写 `属性.标题:` 或 `prop.标题:`。

## 日期

`创建:`、`修改:` 与日期属性都支持：

- 一年、一月、一天：`2026`、`2026-09`、`2026-09-01`（也可以用 `/` 或 `.` 分隔）；
- 相对日期：`今天` `昨天` `本周` `上周` `本月` `上月` `今年`，`7天`（含今天在内的最近 7 天）；
- 比较：`>=2026-09-01`、`<本月`；区间：`2026-09..2026-10`，一端可以空着（`2026-01..`）。

按本机时区的自然日计算。保存为常用检索时，“本周”“7天”这类相对日期每次打开都按当天重新计算。

## 排序

有关键词时默认按相关度（标题命中 > 标签、属性 > 正文 > 答案、解析、笔记），并在列表里显示命中片段；没有关键词时按添加时间。可以随时切换成“最近添加”“最近修改”或按某个单选属性排序。

## 出错时

- 语法问题（多余的 `OR`、括号没配对、`标签:` 后面没写值）会被忽略并提示，其余条件照常生效。
- 找不到的选项、学生，无法识别的日期：这个条件视为“不匹配任何内容”并标红，避免打错字时悄悄放宽结果。
- 不认识的键（例如 `作者:张三`）按普通文字查找，并给出提示。

## 常用检索

在“条件”面板里给当前条件起个名字即可保存，之后出现在左侧导航里（带数量）。右键可以改名、调整顺序、删除。属性、选项、学生改名后常用检索依然有效；标签、学科、学段在数据管理里改名或合并时会跟着改写；选项被合并时改指向合并目标。条件里的选项或标签被删除时，导航里会用颜色标出，悬停可以看到原因。
